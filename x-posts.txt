# Xの投稿を「確実に」サイトへ載せたいときに使うファイルです。
#
# 通常は何もしなくても、サイトがXから自動で投稿を取り込みます。
# ただしXの仕様で、投稿したばかりのポストは自動では取得できないことがあります。
# その場合は、ポストのURLを下に1行ずつ貼り付けて保存（Commit）してください。
# 保存すると数分でサイトに反映され、新しい順に3件が表示されます。
# 古いURLは残したままで構いません。
#
# 例:
# https://x.com/kiyotaka_no_uji/status/1974003882855453166

https://x.com/kiyotaka_no_uji/status/1966771283791921562
